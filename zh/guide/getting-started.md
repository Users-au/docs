# 快速开始

Users.au 为项目托管登录和账户管理。用户从你的应用跳转到项目登录，返回后由你的应用建立会话并检查访问权限。

## 创建项目并登记应用

1. 打开 [Users.au 控制台](https://my.users.au/)，创建或选择项目，记下登录源地址，例如 `https://identity.example.com`。接入过程统一使用此地址。
2. 在项目后台打开 **已连接的应用（OAuth）**，登记应用。登录使用授权码流程。纯浏览器应用选择公开客户端，由可信后端交换授权码的应用选择机密客户端。
3. 登记接入指南给出的完整回调地址。例如，Next.js Starter Kit 的开发地址为 `http://localhost:3000/auth/usersau/callback`，生产地址可以是 `https://app.example.com/auth/usersau/callback`。为每个环境单独登记。
4. 将 Client ID 写入应用配置。机密客户端的 Client Secret 显示时立即保存到后端密钥存储，避免进入浏览器构建产物和版本库。
5. [选择接入方式](../integrations/index.md)，从应用发起登录。

## 上线前验证

- 测试成功登录、用户取消登录和回调被拒绝的情况。
- 登录后在应用中检查成员资格和角色。使用签发方和用户主体标识的组合识别账户。
- 检查应用会话与托管账户的退出行为。分别验证退出返回地址和 OAuth 回调地址。
- 浏览器客户端需要配置允许跨域调用 Token 和 UserInfo 的应用来源。排错时逐项核对协议、主机和端口。
- 使用独立浏览器会话测试[项目登录与恢复设置](project-admin.md)。
