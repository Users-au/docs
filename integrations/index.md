# Choose an integration

| Application | Guide | What it provides |
| --- | --- | --- |
| Vanilla JavaScript or TypeScript, Vue 3, React, browser-based Next.js | [Frontend Client](frontend-client.md) | Browser sign-in with authorization code and PKCE. |
| An existing Laravel application | [Laravel Client](laravel-client.md) | Routes, configuration, migrations and local account integration. |
| An existing Laravel app with custom authentication controllers | [Laravel Socialite](socialite-provider.md) | A Users.au OAuth provider for Socialite. |
| A new Laravel application | [Laravel Starter Kit](laravel-starter-kit.md) | An example app with a login page and an authenticated dashboard. |
| A new Next.js application with server-side sign-in | [Next.js Starter Kit](nextjs-starter-kit.md) | NextAuth, server-side credentials and application access checks. |
| Synology DSM | [Synology DSM](synology-dsm.md) | OpenID Connect SSO mapped to existing DSM accounts. |
| Another framework or OIDC client | [OAuth & OpenID Connect](../guide/oauth-oidc.md) | Discovery and the authorization-code flow. |

The [Users-au GitHub organization](https://github.com/Users-au) hosts the SDKs and starter kits. Follow each repository's runtime and version requirements.
